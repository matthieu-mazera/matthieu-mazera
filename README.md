# exxio — a sovereign infrastructure lab

**exxio** is a personal infrastructure lab, built with free software, hosted in Europe, and documented by evidence: every decision is recorded with the command that proves it.

🌐 **Website:** [exxio.eu](https://exxio.eu) — engineering journal and decision records
🇫🇷 Laboratoire d'infrastructure souverain · 🇩🇪 Souveränes Infrastrukturlabor

## Where the work lives

My active work is on **[Codeberg](https://codeberg.org/exxio)**, a non-profit forge based in Berlin (EU). That is why this GitHub account shows few pushes: it is not where I build, it is where I watch.

The lab runs on two Raspberry Pi 5 (ARM64) and a Mac mini: Kubernetes, GitOps reconciliation, a self-hosted forge, a static site generated by Zola, and backups encrypted on two separate disks.

## How I work

- **Measure before acting:** every change is checked on a disposable copy before it touches production.
- **Decisions on record:** architecture choices are written as decision records, each with its proof.
- **Sovereignty by default:** free software, European hosting, no personal data leaving the machine unfiltered.

## What this account is for

- ⭐ **Stars = my technology watch:** GitOps (Flux, Kargo), eBPF networking and security (Cilium, Tetragon), software supply chain (Syft, Grype, OpenVEX, OpenSSF), AI agents and their protocols (MCP, A2A, goose).
- 🗂 **An archive, being cleaned up:** forks from 2020–21, when I explored the JAMstack. One is kept on purpose: **Eleventy**, where an evaluation began that ended, years later, with a documented choice of Zola for exxio.eu.
